# PCBs to manufacture

This is the authoritative generated production output. See [the selected boards and
quantities](<../README.md>). The microphone holder is **microphone-flex Rev C**.

Download `assembly/colloquy-production.zip` for the complete set, or the
`assembly/<board>/<board>-manufacturing.zip` package for a single board.
Read `README-JLCPCB.md` inside each package before uploading its Gerbers, BOM and CPL.
The `web/` folder contains schematic SVGs and 45° 3D previews used by the server.

Regenerate with `export_jlcpcb.py` from the repository root using KiCad Python.
`manifest.json` and the package manifests record the checked source hashes.
Original and superseded exports belong in `../old-reference`.
