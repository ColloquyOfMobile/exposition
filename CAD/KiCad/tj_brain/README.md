# TJ Brain – one Teensy 4.1 brain per unit

This board brings back the distributed 2018 architecture of T. J. McLeish
(one controller per mobile) with a Teensy 4.1. The **same board** is used for
the three females, the two males and the bar. A DIP switch sets which unit it is.

```
            computer (Python server)
                 │ USB
        7-port powered USB 2.0 hub ───────────────┐ one USB cable per brain
                 │                                │ (Teensy micro-USB)
   12V PSU ──┐   │                                ▼
   5V  PSU ──┴─► TJ BACKPLANE ──Mini-Fit Jr 4p──► TJ BRAIN ×6 (F1 F2 F3 M1 M2 BAR) + spare
                 (fused splitter,                    │
                  powers the hub)                    ├─ DXL1-3 (JST EH) ─ Dynamixel X TTL
                                                     ├─ NP1-4 (pluggable 5.08) ─ NeoPixels
                                                     ├─ SPK, LS1-4, MIC, STATE1-2 (JST XH)
                                                     └─ BODY DA-15 ─ into the female (or male) body
```

* Schematic: `tj_brain.kicad_sch` (9 sheets), PCB: `tj_brain.kicad_pcb`
  (180 × 136 mm, 2 layers, 1.6 mm, 1 oz copper is enough on this board).
* Manufacturing files in `fab/`: Gerbers and drill files (zipped), pick-and-place, BOM,
  schematic PDF, assembly drawing, top and bottom renders.
* Custom parts (Teensy 4.1 socket, SparkFun TPA2005D1 breakout) are in `../tj_library`.
* Everything is generated by `../generator` (see the last section). Edit the generator
  and regenerate rather than editing the KiCad files by hand, or the next run overwrites
  your changes.

(J1/J5 there). The existing female body harnesses plug in unchanged. Pins 1, 2, 3, 9, 10
and 11 were unused there and now carry what a male body needs.

Check this against your harness connectors before ordering.

## LEDs

| LED | Meaning |
|-----|---------|
| 12V, 5V, 3V3 | rail present on the board |
| BODY12, BODY5 | rail present on the DA-15 after its PTC (off = PTC tripped) |
| HB, HOST, ERR, USER | driven by firmware (heartbeat, host connected, error, free) |
| NP1–NP4 | data on that NeoPixel output (hardware pulse stretcher, ~50 ms per frame) |
| DXL TX | the Teensy is transmitting on the Dynamixel bus |
| DXL BUS | any traffic on the Dynamixel bus (TX or replies) |
| TONE | tone output active |
| PROBE | free logic probe: touch J19 to any 0–12 V signal |
| LIGHT1–4 | sensor above the threshold set with trimmer TH1–4 (LM339). Use it to aim the beams |
| STATE1, STATE2 | state output switched on (brightness follows PWM) |

## Teensy 4.1 pin map

The pin map is also in `Source code/Teensy/tj_brain_test/tj_brain_pins.h`.

| Pin | Function | Pin | Function |
|----:|----------|----:|----------|
| 0 / 1 | Dynamixel RX1 / TX1 | 14 (A0) | LS1 |
| 2 | Dynamixel DIR (1 = TX) | 15 (A1) | LS2 |
| 3 / 4 | STATE1 / STATE2 (PWM) | 16 (A2) | MIC |
| 5 | AMP_EN (amp shutdown, high = on) | 17 (A3) | LS3 |
| 6, 7, 11, 28 | unit ID bits 0–3 (SW1) | 18 / 19 | SDA / SCL (J2) |
| 8 | NP1 (TX2) | 20 (A6) | LS4 |
| 29 | NP2 (TX7) | 21 (A7) | MSGEQ7 OUT |
| 35 | NP3 (TX8) | 22 (A8) | AUX (DA-15 pin 11) |
| 24 | NP4 (TX6) | 23, 25, 26, 27, 40, 41 | expansion J2 |
| 9 / 10 | MSGEQ7 STROBE / RESET | 30, 31, 32, 37 | LEDs HB, HOST, ERR, USER |
| 12 | AUDIO (tone() or MQSL) | 13, 33, 34, 36, 38, 39 | free (13 = on-board LED) |

The four NeoPixel pins are serial TX pins, so the `WS2812Serial` (DMA, non-blocking) or
`OctoWS2811` libraries can drive them without stopping interrupts. The Dynamixel bus works
with `Dynamixel2Arduino dxl(Serial1, 2);`.

## Unit ID (SW1)

Switch 1 is bit 0, and a switch set to ON counts as 1. The firmware reads it with
`readUnitId()` and reports its role to the host. The host can then open the right serial
port for each unit without having to remember port names.

| ID | Unit | SW1 1-2-3-4 | Dynamixel ids (unchanged) |
|---:|------|-------------|---------------------------|
| 1 | female1 | ON off off off | 1 body, 2 mirror |
| 2 | female2 | off ON off off | 3, 4 |
| 3 | female3 | ON ON off off | 5, 6 |
| 4 | male1 | off off ON off | 7 |
| 5 | male2 | ON off ON off | 8 |
| 6 | bar | off ON ON off | 9 |

### Tone filter (R23 = R24, C10 = C11)

These values come from T. Erforth's "Pask redesign" (Table 2). The board default is the
1 kHz set. Fit the set that matches each unit's band.

| Band | R | C |
|-----:|---|---|
| 160 Hz | 2k2 | 470 nF |
| 400 Hz | 2k | 220 nF |
| 1 kHz | 1k2 | 150 nF |
| 2.5 kHz | 1k8 | 47 nF |
| 6.25 kHz | 2k2 | 10 nF |

* If the Teensy generates a sine wave instead (Audio library on MQS pin 12), use
  2k2 / 10 nF for every unit. The filter then only removes the MQS carrier.
* The divider is 22k / 6k8 instead of Thomas's 22k / 3k3. The Teensy swings 3.3 Vpp
  instead of 5 Vpp, so this ratio still gives about 330 mVpp at the amplifier.

### Amplifier options

* **On-board** (default): SparkFun BOB-11044 (TPA2005D1) plugged in at U5, volume on RV1.
  This is the same footprint as the electronic box. AMP_EN can mute it.
* **Amp next to the speaker** (Thomas's recommendation for the class-D EMI):
  1. Leave U5 out.
  2. Close JP1 and JP2. The DA-15 pins 12/4 then carry the line level (AC coupled) and GND.
  3. Power the GF1002 module in the body from DA-15 pin 15 (5V).
  4. Instead of steps 2–3, a module on the board can be wired to the EXT AMP header J10.

### Sensors and microphone

* The light sensor inputs accept 0–5 V modules, as in the old box. A 10k/18k divider keeps
  the ADC below 3.3 V.
* For a bare LDR, the 28 kΩ divider is the pull-down. Wire the LDR between VCC and the
  signal pin.
* Sensor VCC is 5V by default. Cut JP4 and bridge it to the 3V3 side for 3.3 V sensors.
  JP3 does the same for the microphone.
* The microphone input (MAX9814, bias 1.25 V, 2 Vpp) has a 1 kΩ resistor and a BAT54S
  clamp. It goes both to A2 and, through 22 kΩ + 10 nF, to the optional socketed MSGEQ7.
* The MSGEQ7 runs at 3.3 V, so its output fits the ADC. Pin 6 is decoupled with 100 nF
  as the datasheet requires; it is not tied to GND.

## Assembly notes

* **Teensy power**: VIN is fed from +5V through a B5819W Schottky diode. The VIN/VUSB
  trace on the Teensy can stay **uncut**: the diode keeps the backplane 5V and the PC
  USB 5V from feeding each other. The Teensy then runs from whichever supply is higher.
* Mount the Teensy on 2× 1×24 female headers. Its USB connector is at the board edge.
  Use a micro-USB cable with strain relief, and tie the cable to the enclosure.
* All SMD parts are 0805 / SOT-23 / SOIC on the top side with hand-solder pads. The
  MSGEQ7 is socketed.
* PTCs: F1 = Bourns MF-RHT300 (body 12V), F2 = MF-RHT400 (body 5V).
* Before plugging the body in, set the four LIGHT thresholds (TH1–4) with the sensors
  installed.
* Bring-up: flash `Source code/Teensy/tj_brain_test`. It prints the unit ID and all the
  analog inputs, pings Dynamixel ids 1–10, and blinks every activity LED.

## Verification done

* The schematic was exported to a netlist with `kicad-cli` and compared net-by-net with
  the design description. Every net matches.
* The PCB was checked with the KiCad DRC; see the "Status" section of
  `../generator/README.md` for the last result.
* Not checked: the custom footprints (Teensy 4.1 and SparkFun breakout) against real
  parts, the D-sub gender against the existing harness, and the Mini-Fit orientation in
  the enclosure. Check these on the first board before a full run.

## Regenerating

```
cd CAD/KiCad/generator
python3 make_lib.py            # TJ symbol / footprint library
python3 build_brain_sch.py     # schematic + netlist self-check
python3 build_brain_pcb.py     # placement, power trunks, GND vias, pours, silkscreen
python3 route_brain.py         # autorouter (A* grid router, router.py) + rip-up & reroute rounds
python3 repair_brain.py        # optional: more rip-up rounds on the saved routes
python3 finish_brain.py        # zone fill, DRC, project files and fab outputs
```

These scripts need KiCad 7+ (`pcbnew` Python module, `kicad-cli`) plus numpy and scipy.
Installing `numba` is optional but makes the router about 50× faster.
The files are written in the KiCad 7 format; KiCad 8 and 9 open and upgrade them.
