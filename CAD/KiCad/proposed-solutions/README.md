# Editable designs

Current replacement designs and alternatives live here. Only the seven boards listed
in [the electronics index](../README.md) are selected for manufacture. In particular,
`electronic box v2` and `thomas-or-teensy` are alternative main-board studies.

Use `shields/microphone-flex` for the production microphone holder. Original boards
are preserved under `../old-reference`; purchased-module references are under
`../provided-elements`. Generated order files are under `../production`.
