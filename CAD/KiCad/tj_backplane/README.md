# TJ Backplane – 12V / 5V splitter (+ USB hub supply)

The backplane no longer carries signals between units. It now only splits power to the
brain boards:

* **12V** (Dynamixels) and **5V** (NeoPixels and logic) from two PSUs go to up to
  seven TJ Brain boards: F1, F2, F3, M1, M2, BAR and one spare.
* **USB** goes through a commercial 7-port *powered* USB 2.0 hub next to the backplane.
  The backplane powers the hub from its `HUB 5V OUT` terminal (fused). Each brain gets
  its own USB A to micro-B cable into the Teensy. The computer then sees six
  independent serial ports, and each Teensy reports its unit ID.

There is no hub chip on this board. I could not get a hub IC datasheet (FE1.1s etc.)
from inside the design sandbox, and a high-speed USB hub designed from memory would be
a weak point. A good industrial hub is cheap and proven.

## Board

200 × 85 mm, 2 layers. **Order it with 2 oz copper**: the 5V input carries up to about
25 A. The top layer has a solid +5V plane from the input to all the 5V fuses; the
bottom layer is GND.

| Ref | Function |
|-----|----------|
| J1 | 12V in, Phoenix MKDS 1,5/2-5.08 (1 = +12V, 2 = GND), ≤ 10 A |
| J2 | 5V in, Phoenix MKDS 1,5/4-5.08 (1, 2 = +5V; 3, 4 = GND), two poles in parallel, ≤ 25 A |
| J3 | HUB 5V OUT, MKDS 2p (1 = +5V, 2 = GND), PTC 3 A. Make a pigtail to the hub's DC plug |
| J4–J10 | outputs F1 F2 F3 M1 M2 BAR SPARE, Molex Mini-Fit Jr 5566-04A vertical |
| per output | PTC 3 A (MF-RHT300) on 12V and 5 A (MF-RHT500) on 5V, one LED per rail after its fuse |
| D1/D2, C1/C2 | input TVS (SMBJ15A / SMBJ5.0A) and bulk capacitors |

### Output / brain cable

Make each cable with a Mini-Fit Jr receptacle housing (Molex 39-01-2040, 5557-04R) at
**both** ends, crimp terminals 39-00-0039, and 18 AWG wire wired **pin to pin**:

| Pin | Wire | Signal |
|----:|------|--------|
| 1 | red | +12V |
| 2 | orange | +5V |
| 3 | black | GND |
| 4 | black | GND |

The brain uses the right-angle header 5569-04A1 with the same numbering.

An LED that is off means that rail is missing or its PTC has tripped. Unplug the load,
wait a few seconds, and the PTC resets.
